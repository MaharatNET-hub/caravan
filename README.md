# موقع جمعية الكرفانات — Caravan Association

موقع ثابت (HTML / CSS / JavaScript) بالعربية، متجاوب مع الجوال، ويدعم الوضع الليلي.
لا يحتاج أي إطار عمل أو خطوة بناء: افتح `index.html` في المتصفح، أو ارفع المجلد كما هو على أي استضافة.

## هيكل المجلد

```
caravan-association/
├── index.html              كل صفحات الموقع (التنقل داخلي عبر #/اسم-الصفحة)
├── README.md
└── assets/
    ├── css/style.css       التصميم والهوية البصرية (الألوان في أول الملف :root)
    ├── js/data.js          ← كل محتوى الموقع القابل للتعديل
    ├── js/scenes.js        الرسومات التوضيحية (كرفانات، صحراء، ساحل، جبال، ليل)
    ├── js/app.js           منطق الصفحات والنماذج والتنقل
    ├── js/motion.js        الحركة والانيميشن
    ├── js/vendor/qrcode.js مكتبة رموز QR (MIT)
    └── img/                الشعار بنسختيه، الرمز، أيقونة المتصفح
```

## تعديل المحتوى

كل المحتوى في `assets/js/data.js`، مقسوم إلى جزأين:

**1. بيانات حقيقية** مأخوذة من النظام الأساسي المعتمد ونموذج ع/01 وحساب إنستغرام:
`SITES`, `NEWS`, `CHAPTERS`, `FAQ`, `ARTICLES`.

**2. بيانات تجريبية — يجب استبدالها قبل الإطلاق:**

- `CONTACT` — الهاتف والواتساب والبريد وساعات العمل (أرقام وهمية).
- `EVENTS` — مواعيد الفعاليات وأسعارها وسعتها.
- `PRODUCTS` — منتجات المتجر وأسعارها.
- `COMPANIES` — أسماء الشركات والرعاة (أسماء مُختلَقة لا تمثّل جهات حقيقية).
- `INVEST` — فرص الاستثمار والرعاية.
- `TOPICS`, `REVIEWS` — مواضيع المنتدى والتقييمات.

الصفحات التي تعرض بيانات تجريبية عليها ملاحظة صغيرة «بيانات تجريبية»؛ احذفوها من `index.html` (ابحثوا عن `samplenote`) بعد إدخال البيانات الفعلية.
كذلك نتيجة التحقق التجريبية للرقم `CA-1001` موجودة في `app.js` (ابحثوا عن `CA1001`).

## ما يحتاج ربطاً بخادم (Back-end)

الموقع حالياً واجهة كاملة تعمل في المتصفح، ويحفظ ما يدخله الزائر على جهازه (localStorage). للتشغيل الفعلي يلزم ربط:

1. **نموذج الانضمام** ← لوحة تحكم لأمين السر وقاعدة بيانات الأعضاء وإشعارات بالبريد/واتساب.
2. **الدفع** ← بوابة دفع (بطاقات، Apple Pay، Google Pay) لرسوم العضوية والفعاليات والمتجر.
3. **التحقق من العضوية** ← واجهة API تُرجع الاسم والنوع والحالة وتاريخ الانتهاء فقط.
4. **تسجيل الفعاليات** ← حفظ التسجيلات وإرسال التذاكر بالبريد وتطبيق مسح QR للمنظمين.
5. **نماذج التواصل والبلاغات** ← بريد الجمعية أو نظام تذاكر.
6. **المنتدى والتقييمات** ← حسابات أعضاء وإشراف على المحتوى.

مواضع الربط في `app.js`: دوال `finish()` (العضوية)، `openReg()` (الفعاليات)، `checkout` (المتجر)، `cform submit` (التواصل)، `verify()` (التحقق).

## الرسومات والحركة

**الرسومات:** كل الصور في الموقع رسومات SVG مرسومة بالكود بألوان الهوية (`scenes.js`)، فهي خفيفة وحادّة على كل الشاشات ولا تحتاج حقوق نشر. المشاهد المتاحة: `coast` ساحل، `mountain` جبل، `kite` كايت سيرف، `tiles` مواقف مرصوفة، `night` مخيم ليلي، `desert` غروب صحراوي.

**إضافة صور حقيقية للمواقف:** ضعوا الصورة في `assets/img/sites/` ثم اكتبوا مسارها في حقل `img` للموقع داخل `data.js`، مثل:
`img:'assets/img/sites/dhanna-port.jpg'` — تظهر الصورة تلقائياً بدل الرسمة (يُفضَّل 1200×700 بصيغة JPG أو WebP).

**الحركة:**
- الهيرو: النص يظهر تدريجياً، والشعار يطفو، والطريق الذهبي يُرسم، وكرفان يقطع الطريق، ونار مخيم وصور نجوم تتلألأ، وطبقات الكثبان تتحرك مع التمرير والمؤشر (Parallax).
- رؤوس الصفحات: سيارة تسحب كرفاناً تدخل المشهد عند فتح كل صفحة.
- ظهور تدريجي للعناصر عند التمرير، وعدّادات للأرقام، وانتقال ناعم بين الصفحات (View Transitions).
- الهيدر يصغر عند التمرير مع شريط تقدّم ذهبي، وزر للعودة للأعلى، وشريط رعاة متحرك.
- البطاقات: رفع وضوء يتبع المؤشر وتكبير للصورة، والأزرار بلمعة ذهبية.
- كل الحركة تتوقف تلقائياً لمن فعّل «تقليل الحركة» في جهازه.
